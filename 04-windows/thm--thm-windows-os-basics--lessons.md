06. OPERATING SYSTEMS: INTRODUCTION
Источник: https://tryhackme.com/room/operatingsystemsintroduction
Конспект прочитанной части: роль ОС, обязанности и разделение привилегий.

ОС координирует работу приложений и оборудования. Основные обязанности:
управление процессами и временем CPU; выделение и освобождение памяти;
организация файлов, метаданных и прав; учетные записи и аутентификация;
подключение устройств через драйверы.

Kernel space — привилегированная область ядра, управляющего ресурсами.
User space — область обычных приложений с ограничениями. Для операций,
которые требуют участия ядра, приложение использует system call —
системный вызов. Это разделение помогает изолировать приложения.

Защита начинается на уровне ОС: проверка личности пользователя,
разрешения на чтение, запись и исполнение, изоляция процессов и защита
системных настроек. GUI дает графическое управление; CLI — команды.
В практике нужно исследовать учебную машину через About This Computer.

07. WINDOWS BASICS
Источник: https://tryhackme.com/room/windowsbasics
Конспект прочитанной части: рабочая среда, учетные записи и файлы.

В учебном сценарии новая рабочая станция использует Windows Server 2019.
Рабочий стол содержит файлы, папки и ярлыки; панель задач помогает открывать
и переключать приложения. Start и Search дают доступ к программам,
настройкам и системной информации. About your PC показывает сведения
об устройстве и ОС.

Учетные записи отличаются разрешениями: Guest предназначен для
ограниченного временного доступа; Standard — для обычных действий;
Administrator — для управления системой. Это различие важно при работе
с настройками и файлами.

File Explorer использует иерархию папок. Комната предлагает освоить пути,
организацию документов и встроенные инструменты: Settings, Task Manager
и Windows Security. Конкретные ответы из учебной рабочей станции
не получены. Данный блок не является конспектом всех заданий комнаты.
