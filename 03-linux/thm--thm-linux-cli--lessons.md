# Linux CLI: навигация и поиск

Сводка прочитанного материала, 20.10.2026. Не является полным курсом.

04. LINUX FUNDAMENTALS PART 1
Источник: https://tryhackme.com/room/linuxfundamentalspart1
В комнате заголовок Linux Fundamentals (Pt1).

CLI — текстовое управление системой через терминал. Пользователь влияет
на доступные действия, поэтому работа начинается с проверки учетной записи.
Основные команды урока:
whoami — текущий пользователь;
echo "hello world" — вывести текст;
pwd — показать текущий каталог;
ls — перечислить содержимое;
cd — перейти в каталог;
cat — прочитать файл;
find -name passwords.txt — найти файл по имени;
grep "password123" passwords.txt — искать строку внутри файла;
grep "THM" access.log — пример поиска флага в учебном журнале.

Операторы оболочки: & запускает работу в фоне; > направляет вывод в файл
с перезаписью; >> дописывает вывод в конец файла. В уроке также вводится
&& для последовательного объединения команд. Пример перенаправления:
echo hey > welcome
cat welcome

Практика требует учебной Ubuntu-машины. Ее файлы и флаг не проверены.
