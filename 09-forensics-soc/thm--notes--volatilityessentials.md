# Volatility Essentials

Источник: https://tryhackme.com/room/volatilityessentials
Авторский краткий конспект основных приёмов Task 1–8; не полная лекция.

Task 1–2. Volatility анализирует снимок оперативной памяти. В архитектуре
Volatility 3 используются слои адресного пространства, символы и плагины.

Task 3. Получение дампа и его исследование — разные этапы. Сохраняй
целостность исходника и сведения о получении. Начни с описания системы:
`python3 vol.py -f MEMORY_IMAGE windows.info`.
MEMORY_IMAGE необходимо заменить путём к предоставленному дампу.

Task 4. `windows.pslist` перечисляет процессы по списку, `windows.psscan`
ищет структуры процессов, `windows.pstree` показывает родство.
`windows.handles` исследует открытые объекты, `windows.dlllist` — DLL;
`windows.netstat` и `windows.netscan` используются для сетевых артефактов.
Сопоставляй PID, родителя, путь и время, а не только имя процесса.

Task 5. `windows.malfind` выделяет области для проверки на инъекции;
`windows.vadinfo` помогает исследовать виртуальные области памяти.
Срабатывание — основание для исследования, а не готовый вердикт.

Task 6. `windows.ssdt`, `windows.modules` и `windows.driverscan`
помогают исследовать ядро и драйверы. Перехват функции сам по себе
не доказывает заражение: важен контекст использования.

Task 7–8. Практика связывает подозрительный процесс с путём, родителем
и сетевыми признаками. Значения из учебного вывода не являются результатом
анализа пользовательского дампа. Не все плагины обязаны вернуть данные.
Имена и доступность плагинов сверяй с `python3 vol.py -h` своей установки.
