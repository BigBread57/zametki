# Cold Boot: устройство компьютера

Источник: https://tryhackme.com/room/insideacomputer

Прочитаны вступление, Case File и Parts & Function интерактивной лаборатории.
Это частичный конспект: сборка компьютера и последующие экраны не пройдены.
Вторая ссылка `insideacomputerQwe` показала тот же интерфейс Cold Boot.

Вместо обычных Task комната открывает встроенный сценарий. По условию
нужно изучить бирки компонентов, выбрать семь подходящих частей, собрать
компьютер и восстановить файл доказательства. Часть деталей — отвлекающие.
Флаг и итоговый отчёт в этом проекте не получены и не отправлялись.

Справочник объясняет назначение компонентов:

- CPU исполняет инструкции; в показанной машине устанавливается в сокет.
- RAM хранит используемые данные временно и теряет содержимое без питания;
  модули размещаются в DIMM-слотах.
- PSU преобразует сетевое питание для внутренних компонентов.
- Сетевой адаптер обеспечивает обмен данными; USB Wi-Fi адаптер добавляет
  беспроводное подключение через внешний USB-порт.
- I/O-панель предоставляет внешние разъёмы, включая USB, HDMI и Ethernet.
- SSD сохраняет файлы без движущихся частей, HDD использует магнитные диски.
- GPU формирует изображение; в настольной конфигурации показан PCIe x16,
  в ноутбуке размещение зависит от конструкции.

Показанное расположение SSD на плате относится к сценарию. Не следует
приписывать такой форм-фактор всем SSD. Функция детали сама по себе
не доказывает, что именно она принадлежит исследуемому компьютеру:
в упражнении нужно читать сведения на бирках.
