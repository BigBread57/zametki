# 01. OFFENSIVE SECURITY INTRO
Источник: https://tryhackme.com/room/offensivesecurityintro

Offensive security — поиск слабых мест с позиции атакующего. Учебная
комната показывает этот подход на специально созданном банке FakeBank.

Ход работы:
1. Открыть учебный виртуальный рабочий стол с приложением FakeBank.
2. Через терминал запустить поиск скрытых страниц:
   dirb http://fakebank.thm
3. В выводе Dirb строки с «+» обозначают найденные страницы.
4. Изучить административную страницу /bank-transfer. По тексту задания
   она позволяет добавить деньги на счет 8881. Задание предлагает внести
   не менее $2000 и проверить, что баланс стал положительным.

Вывод: отсутствие ссылки на страницу не предотвращает ее обнаружение.
В этом учебном сценарии найденная административная функция позволяет
изменять баланс. Результат запуска и итоговый флаг не получены.
