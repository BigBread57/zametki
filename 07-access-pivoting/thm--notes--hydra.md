# Hydra

Источник: https://tryhackme.com/room/hydra
Авторский конспект Task 1–2.

Task 1. Hydra проверяет пароли через сетевую аутентификацию.
Это online-проверка сервиса, а не вычисление пароля из локального хэша.
Конкретный модуль выбирается под протокол.

Task 2. Для лабораторного SSH пример строится так:

```text
hydra -l LAB_USER -P passwords.txt LAB_IP -t 4 ssh
```

`-l` задаёт одного пользователя, `-P` — файл паролей, `-t` — число
параллельных задач. Для нестандартного порта предусмотрен `-s`.
LAB_USER и LAB_IP — заменяемые значения своей лаборатории.

Для HTTP-формы сначала выясни настоящий метод запроса, путь, имена
полей и ответ при неверном пароле. В модуле `http-post-form` строка
содержит три части: путь, тело запроса, признак результата.
`^USER^` и `^PASS^` — места подстановки. В примере урока
`F=incorrect` задаёт текст, означающий неудачу; у другой формы он иной.
`-V` печатает попытки и способен раскрыть используемые пароли в журнале.

Результат зависит от правильной модели ответа приложения. Не объявляй
пару действительной только по ошибочно выбранной строке неудачи.
В этом проекте подбор не запускался; пароли и два учебных флага
не получены. Отдельный вывод защиты: сменить известные пароли по умолчанию.
