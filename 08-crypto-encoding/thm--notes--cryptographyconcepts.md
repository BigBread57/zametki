# 15. CRYPTOGRAPHY CONCEPTS
Источник: https://tryhackme.com/room/cryptographyconcepts

Plaintext — открытые данные; ciphertext — зашифрованные. Алгоритм задает
преобразование, ключ управляет им. Урок подчеркивает: алгоритм может быть
публичным, секретность ключа критична.

Симметричное шифрование использует общий секретный ключ для шифрования
и расшифрования. Оно эффективно для больших объемов данных, но требует
решения задачи безопасного распределения ключа.

Шифр Цезаря демонстрирует сдвиг букв: HELLO при сдвиге 3 дает KHOOR.
Он приведен исключительно для обучения; для реальной защиты не подходит.
AES назван примером современного симметричного алгоритма.

Асимметрическая схема использует открытый и закрытый ключи. В примере
отправитель шифрует сообщение открытым ключом получателя; расшифровать
его должен владелец соответствующего закрытого ключа.

Сертификат связывает открытый ключ с владельцем. CA — удостоверяющий
центр. Комната объясняет гибридный подход: механизмы с открытым ключом
участвуют в установлении защищенного соединения, симметричные защищают
основной поток данных. Практическая игра и просмотр сертификатов
не выполнены; флаг не получен.
