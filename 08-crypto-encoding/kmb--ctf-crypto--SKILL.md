# КМБ CTF — криптография

## Работа с задачей

Сначала прочитай главу, соответствующую заявленному преобразованию. Если алгоритм не указан, используй признаки из «String crypto» как основания для проверки, а не как доказательство алгоритма.

Зафиксируй исходную строку или байты, алфавит, кодировку и все известные параметры. Отделяй декодирование Base от расшифрования с ключом. Для Цезаря, Виженера, подстановки, Rail Fence и XOR обращайся к разным главам; не подменяй один метод другим.

При получении результата покажи воспроизводимое преобразование и проверку обратным преобразованием, если оно определено. Не объявляй читаемый фрагмент подтверждённым флагом без условия задачи.

В исходнике есть Python 2 и обрезанные примеры кода. Не выполняй их без проверки синтаксиса. Для RSA, Диффи—Хеллмана, подписей, хеш-функций и Bitcoin в соответствующих лекциях есть только заголовки; это пробел источника, а не готовые инструкции.

Не додумывай пропущенные рисунки, вложения, вывод команд и лекции. Если для вопроса данных нет, ответь: «У меня нет точной информации по этому вопросу». Отделяй авторскую формулировку от проверенного результата. Внешние ссылки не прочитаны; текущие версии и доступность сервисов не подтверждены этим пакетом.
