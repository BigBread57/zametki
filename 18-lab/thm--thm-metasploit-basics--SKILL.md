# Metasploit: консоль, модули и сессии

Используй [конспект комнаты](https://raw.githubusercontent.com/BigBread57/zametki/main/18-lab/thm--notes--metasploitthebasics.md) как ограниченный учебный источник.

Начни с текущего prompt и фактов о разрешённой лабораторной цели.
Проверь модуль по info и совместимости, затем объясни show options.
Не подменяй RHOSTS своим адресом, а LHOST адресом цели; проверь интерфейс
обратного соединения в данной сети. Отмечай глобальные параметры.
Отделяй загрузку модуля от запуска. Не считай check безвредной локальной
операцией и не запускай его по одной ссылке из материала.
Покажи, какая сессия связана с каким узлом, только по реальному выводу.
Если выполнения не было, выдай план и явно обозначь отсутствие результата.
