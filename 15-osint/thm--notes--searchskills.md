# 03. SEARCH SKILLS
Источник: https://tryhackme.com/room/searchskills

Урок рассматривает несколько разных источников информации.
Shodan ищет доступные из Интернета устройства и сервисы. Примеры фильтров
из урока: country:IE, port:22, hostname:fakebank.thm. Поиск по версии сервера
помогает отбирать записи для дальнейшей проверки.

VirusTotal объединяет результаты антивирусных средств и сканеров.
Проверять можно файл, URL, домен или хеш. Сводная оценка не безошибочна.

CVE — единый идентификатор известной уязвимости, формат CVE-YEAR-NUMBER.
CVSS используется для оценки серьезности. ExploitDB и GitHub содержат
демонстрационные материалы и PoC — proof of concept. PoC нужно проверять
перед запуском: опубликованный код не является гарантией надежности.
В заданиях используется вымышленный CVE-2026-1337; его нельзя выдавать
за подтвержденную реальную уязвимость.

Официальная документация помогает разобраться в параметрах инструмента.
Для локальной справки Linux: man <command>; пример урока: man nc.
Практические ответы требуют работы с симуляциями; они не получены.
