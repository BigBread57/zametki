# Заметки по ИБ и CTF

406 учебных документов из пяти источников, распределённых по 19 темам. Каталоги отсутствующих лекций и пустые шаблоны исключены. Источники и их ограничения сохранены.

**Начните с [INDEX.md](https://github.com/BigBread57/zametki/blob/main/INDEX.md).**

Чтобы использовать библиотеку без скачивания проекта:

1. [Скачайте только INDEX.md](https://raw.githubusercontent.com/BigBread57/zametki/main/INDEX.md) и прикрепите его к разговору с ИИ.
2. Попросите ИИ выбрать документ и открыть ссылку «текст для ИИ» из оглавления.
3. ИИ читает только выбранные документы. Для этого ему нужен инструмент открытия URL и доступ к GitHub. Если такой возможности нет, скачайте и прикрепите конкретный документ сами.

Ссылки на документы абсолютные, включая переходы между материалами. Само оглавление не содержит полного текста всех конспектов и не устанавливает скилы, инструменты или MCP.

[Происхождение, версии и авторские условия](https://github.com/BigBread57/zametki/blob/main/SOURCES.md) · [Состав и SHA-256](https://raw.githubusercontent.com/BigBread57/zametki/main/manifest.json) · [Результат проверки чтения через интернет](https://raw.githubusercontent.com/BigBread57/zametki/main/online-validation.json).

Технические команды из источников не выполнялись и не проверялись целиком. Материалы содержат исходные ограничения, частичные конспекты и исторические примеры. Единая лицензия на всю подборку не назначена; авторские уведомления находятся в SOURCES.md и licenses/.
