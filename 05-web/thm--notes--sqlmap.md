# SQLmap

Источник: https://tryhackme.com/room/sqlmap
Авторский конспект выбранных положений Task 1–3.

Task 1. SQL injection связана с обработкой входа приложением в SQL.
SQLmap автоматизирует проверку параметров и получение сведений о СУБД.

Task 2. `sqlmap -h` показывает основные параметры, `sqlmap -hh` —
расширенную справку. `-u` задаёт URL, `--data` — POST-данные,
`-r` читает сохранённый HTTP-запрос, `-p` ограничивает проверяемый параметр.
В запросе нужны фактические метод, путь, заголовки и тело; проверь,
что сессия ещё действительна. Пример для своей лаборатории:

```text
sqlmap -r request.txt -p blood_group --dbs
sqlmap -r request.txt -p blood_group -D LAB_DB --tables
sqlmap -r request.txt -p blood_group -D LAB_DB -T LAB_TABLE --columns
```

`--dbs`, `--tables` и `--columns` — последовательные уровни перечисления.
`-D`, `-T`, `-C` ограничивают базу, таблицу и столбцы.
`--dump` извлекает записи, это отдельный шаг с другим объёмом данных.
`--level` и `--risk` регулируют проверки; `--batch` выбирает ответы
по умолчанию, а не доказывает корректность результата.

Task 3. Практика требует исследовать учебное приложение. Здесь она
не выполнена: имя пользователя СУБД и флаг не установлены.
Не переносите пример терминального вывода на другую цель.
Сохранённый запрос может содержать cookies: не публикуйте его целиком.
