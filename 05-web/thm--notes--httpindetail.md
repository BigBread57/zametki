# 11. HTTP IN DETAIL
Источник: https://tryhackme.com/room/httpindetail

HTTP передает запросы и ответы веб-приложения; HTTPS защищает соединение
шифрованием и проверкой сервера. URL содержит схему, узел, порт, путь,
параметры запроса и фрагмент. Типовые порты в уроке: 80 и 443.

Методы: GET получает данные; POST отправляет данные для обработки,
в том числе создания; PUT используется для обновления; DELETE — удаления.
Классы статусов: 1xx — информация, 2xx — успех, 3xx — перенаправление,
4xx — ошибка запроса/доступа клиента, 5xx — ошибка сервера.
Примеры: 200 — успех, 201 — создано, 404 — ресурс не найден.

Заголовки: Host выбирает виртуальный сайт; User-Agent описывает клиент;
Content-Type — тип содержимого; Content-Length — длину; Accept-Encoding
и Content-Encoding — поддерживаемое и использованное сжатие.

HTTP не хранит историю запросов сам по себе. Сервер задает cookies через
Set-Cookie, клиент передает их в Cookie. Они помогают связывать запросы
с сессией и настройками. Практика включает запросы разных методов
в симуляторе. Она не выполнена; флаги не получены.
