# 10. DNS IN DETAIL
Источник: https://tryhackme.com/room/dnsindetail

DNS — Domain Name System: поиск записей по доменным именам. Иерархия
в примере admin.tryhackme.com: com — верхний уровень; tryhackme — второй;
admin — поддомен.

Основные записи: A — IPv4; AAAA — IPv6; CNAME — другое доменное имя;
MX — почтовые серверы с приоритетами; TXT — текстовые значения,
включая данные проверки домена и настройки почтовой аутентификации.

Общий процесс: клиент проверяет кэш, затем обращается к рекурсивному
резолверу. При отсутствии кэшированного результата тот получает
направления через корневые и TLD-серверы к авторитетному серверу домена.
Авторитетный сервер содержит его DNS-записи. TTL задает срок кэширования
ответа в секундах.

Практика спрашивает значения A, CNAME, TXT и приоритет MX для учебных
доменов. Эти ответы не подставлены из действующих внешних доменов:
необходима соответствующая учебная симуляция, она не выполнена.
