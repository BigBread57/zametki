# Сети, DNS и HTTP

Прочитай нужный раздел [лекционных заметок](https://raw.githubusercontent.com/BigBread57/zametki/main/02-network/thm--thm-network-dns-http--lessons.md), а не все разделы подряд.

Установи уровень задачи: адресация и LAN, разрешение имени или обмен HTTP. Не смешивай IP и MAC, DNS-ответ и доступность веб-сервера, код HTTP и тело ответа. Для DNS укажи тип записи, резолвер и TTL, если они даны. Для HTTP разбери метод, путь, параметры, заголовки и статус; различай Cookie и Set-Cookie. Привязывай вывод к переданному запросу или ответу; учебный адрес не подменяй живыми результатами другого домена.
