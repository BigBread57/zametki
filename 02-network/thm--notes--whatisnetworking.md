# 08. WHAT IS NETWORKING?
Источник: https://tryhackme.com/room/whatisnetworking

Сеть объединяет устройства для обмена данными. Интернет объединяет
множество сетей. Устройства используют IP-адреса и MAC-адреса интерфейсов.
IPv4 содержит четыре октета; адреса рассматриваются в контексте сети.
В учебном примере два устройства имеют разные частные адреса и один
общий публичный адрес для выхода в Интернет.

MAC записывается шестнадцатеричными парами, например a4:c3:f0:85:ac:2d.
Урок показывает MAC spoofing — подмену этого идентификатора. Следствие
для защиты: доверие только к такому адресу недостаточно.

Ping использует ICMP Echo Request и Echo Reply для проверки ответа узла
и измерения времени обмена. Пример синтаксиса из заданий:
ping 10.10.10.10

В практике требуется работа с симуляциями сети и ping. Ответы симуляций
и флаги не получены. Исторические и статистические отступления комнаты
в конспект не включены.
