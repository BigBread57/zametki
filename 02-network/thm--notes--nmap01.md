# Nmap: обнаружение узлов

Источник: https://tryhackme.com/room/nmap01
Авторский краткий конспект выбранных положений Task 1–9; не копия лекции.

Task 1–3. Обнаружение живых узлов предшествует исследованию сервисов.
Сегмент описывает связь на канальном уровне, подсеть — адресацию IP.
Для поиска используют ARP, ICMP и ответы TCP/UDP.

Task 4. Цель задают списком, диапазоном, CIDR или файлом `-iL`.
`nmap -sL -n TARGETS` проверяет развёрнутый список адресов без поиска узлов
и без обратного DNS. TARGETS — заменяемый параметр, не готовая цель.

Task 5. `-sn` отключает последующее сканирование портов. ARP применим
в локальном сегменте: `sudo nmap -PR -sn LAB_SUBNET`.

Task 6. ICMP: `-PE` — Echo, `-PP` — Timestamp, `-PM` — Address Mask.
Отсутствие ответа не доказывает, что узел выключен: запрос фильтруется.

Task 7. `-PS22,80,443` задаёт TCP SYN ping, `-PA22,80,443` — ACK ping,
`-PU53,161,162` — UDP ping. Добавляй `-sn`, если нужны только узлы.
Ответ RST или ICMP port unreachable тоже несёт сведения о доступности.

Task 8–9. `-n` отключает DNS; `-R` запрашивает обратное разрешение.
Имя из rDNS не является проверенным назначением сервера.
Права пользователя и положение относительно подсети влияют на пробы.

Проверь себя: чем обнаружение узла отличается от определения открытого
порта? Почему один молчащий тип ICMP не даёт окончательного вывода?
Практические результаты и ответы на задания здесь не получены.
