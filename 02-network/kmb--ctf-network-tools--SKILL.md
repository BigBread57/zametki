# КМБ CTF — сетевые утилиты

## Работа с задачей

Выбери инструмент по требуемой операции: обмен TCP/UDP, проверка портов, загрузка файла, SSH-соединение или проверка связности. Читай соответствующий фрагмент справочника, а не весь курс.

Перед сетевым запуском используй адрес, порт и границы проверки из задания пользователя. Адреса из книги остаются примерами. Не расширяй одну цель до подсети и не включай агрессивные режимы автоматически.

В книге смешаны варианты nc/ncat и параметры разных ОС, особенно ping. Проверь установленную реализацию и её локальную справку перед переносом ключей. Возвращай точную команду, фактический вывод и то, что этот вывод подтверждает.

Лекции OSI, TCP/IP, DNS, FTP, SMTP и VPN в скачанном тексте представлены заголовками; не сочиняй по ним содержание.
