# Nmap: обнаружение узлов

Используй [конспект комнаты](https://raw.githubusercontent.com/BigBread57/zametki/main/02-network/thm--notes--nmap01.md) как ограниченный учебный источник.

Уточни разрешённые адреса, локальный сегмент и права процесса.
Сначала объясни развёртку TARGETS, затем выбери один подходящий тип проб.
Для каждой предложенной команды укажи ожидаемый вид ответа и предел вывода.
Не называй молчание доказательством отсутствия узла. Не выдавай discovery
за проверку уязвимостей или открытых портов. Перед фактическим запуском
убедись, что это запрошенная пользователем лаборатория; скил сам ничего
не сканирует. Заверши разбор таблицей «проба → наблюдение → вывод».
