# Происхождение материалов

Материал подготовлен из локальной выгрузки сайта https://kmb.cybber.ru/ — «Курс молодого CTF бойца v 1.5», включая поисковый индекс GitBook, скачанный 20.10.2026. Ссылки на страницы и использованный источник текста записаны в каждом справочном файле и sources/catalog.json. Разделы с упоминанием itsecwiki.org, Hackerdom и других источников сохраняют имеющуюся в тексте атрибуцию.

Рабочие инструкции SKILL.md составлены при подготовке этого пакета; это не дословные авторские инструкции книги. В справочных файлах сохранён доступный текст источника за исключением отдельно помеченной главы RCE. Предположения и ошибки автора не становятся подтверждёнными фактами.

У меня нет точной информации по этому вопросу: лицензия исходной книги и разрешение на публичное распространение её текста. Лицензия на исходные материалы здесь не назначена. Пакет подготовлен для запрошенного пользователем переноса на другой ПК; права авторов не передаются этим архивом.

## Что изменено при сборке

- Документы распределены по темам, имена файлов получили префикс источника. Исходные папки не менялись.
- Удалены служебные каталоги, списки отсутствующих лекций, пустые шаблоны, инвентарь среды автора CTF-Agent и уведомление-заглушка главы RCE. Само наличие кода внутри содержательного документа не являлось причиной исключения.
- Точные совпадения текста после нормализации перевода строк объединены с сохранением всех исходных путей. Материалы по одной теме с разным содержимым оставлены отдельно.
- Добавлены шапки с происхождением, общие правила чтения, абсолютные ссылки для чтения через GitHub и пометки о внешних зависимостях. Ссылки на исключённые перечни недостающих глав удалены.
- Кодовые блоки и команды сохранены как текст источника. Скрипты, бинарные файлы, конфигурации, MCP, установщики, ключи API и словари не включены. Упоминания таких компонентов не означают их доступность.
- Внешние сайты, ссылки и команды из учебных текстов не проверялись на работоспособность. Успех в текущей лаборатории этими материалами не подтверждается.

## Проверка состава

`manifest.json` содержит пути включённых документов, их происхождение и SHA-256. `excluded.json` содержит только имена исключённых файлов и причины; содержимое отсутствующих лекций не копируется. `validation.json` содержит результаты структурной проверки. Эти файлы служат для контроля сборки, а не являются учебными материалами.

## Публикация в zametki

Документы размещены в https://github.com/BigBread57/zametki. Оглавление содержит прямые ссылки на страницу документа и его Markdown-текст. Ссылки между материалами также ведут на полные URL; чтение не требует клонирования репозитория. Эти ссылки указывают на текущую ветку main, поэтому содержимое по ним меняется при обновлении репозитория.

Проверка загрузки отдельных документов без Git выполняется после публикации. Её результаты сохраняются в online-validation.json. Проверка HTTP-доступности не является независимой проверкой технических утверждений и не подтверждает возможности любого приложения ИИ.
